## 30 Interview Questions for Voice-Controlled Video Streaming Platform

### Voice Recognition & Speech-to-Text (Questions 1-5)

1. How is the Web Speech API implemented for voice recognition? Explain the difference between `SpeechRecognition` and `webkitSpeechRecognition` and how browser compatibility is handled.

2. How do you prevent multiple recognition instances from conflicting when the user triggers voice commands from different components (Navbar vs Video component)?

3. How is the 95% recognition accuracy achieved? What techniques are used to improve accuracy, and how do you handle recognition errors or ambiguous commands?

4. Explain the voice search implementation. How does it differ from command recognition, and how is the search query processed and executed?

5. How is the voice message recorder implemented for comments? Describe the 10-second recording limit and the conversion from speech to text before posting.

### Voice Command Parsing & Intent Recognition (Questions 6-10)

6. Explain the command parsing logic in `handleVoiceCommand`. How does it handle variations like "play 3", "play three", "open 2", and "play number 5"?

7. How does the `parseIndexFromText` function work? Explain how it converts both numeric words ("three", "ten") and digits to array indices for video selection.

8. How are ambiguous commands handled? For example, if a user says "play" without specifying an index, how does the system determine the intent?

9. Explain the `extractSeconds` function. How does it parse time-based commands like "forward 10 seconds" or "rewind five seconds" from natural language?

10. How are voice commands for scrolling pages implemented? Describe the scroll speed control and how manual user input interrupts voice-controlled scrolling.

### Video Player Controls & Playback (Questions 11-15)

11. How is Picture-in-Picture (PiP) mode implemented? What browser compatibility considerations exist, and how is it toggled via voice commands?

12. Explain the autoplay implementation with muted fallback. How does the system handle browser autoplay policies and provide an unmute button when needed?

13. How are playback speed controls implemented? Describe how commands like "slow", "normal", "double", and "faster" map to specific playback rates.

14. How is video seeking implemented via voice commands? Explain how "forward 10" and "backward 5 seconds" are converted to actual video time positions.

15. How does the system handle video playback by index? Walk through the flow from voice command "play 3" to navigating to the recommended video.

### Backend Architecture & API Design (Questions 16-20)

16. Explain the RESTful API structure. How are routes organized, and what middleware is applied globally vs per-route?

17. How is the video upload flow implemented? Describe the process from file upload through Multer, Cloudinary processing, and database storage.

18. Explain the JWT authentication system. How are access tokens and refresh tokens generated, stored, and validated? What is the token expiry strategy?

19. How is the like/unlike functionality implemented? Describe the database schema, the toggle logic, and how like counts are calculated efficiently.

20. Explain the subscription system. How are subscription relationships stored, and how is the subscription count calculated and updated in real-time?

### Database & Data Modeling (Questions 21-25)

21. Explain the Video model schema. What fields are indexed, and why? How is the `mongoose-aggregate-paginate-v2` plugin used?

22. How is the Like model designed with `refPath`? Explain how it supports liking both Videos and Messages dynamically.

23. How is the watch history feature implemented? Describe how videos are added to a user's watch history and how this data is queried.

24. Explain the relationship between User, Video, and Message models. How are references and population used to optimize queries?

25. How is view counting implemented? Explain the `incrementViews` method and when it's called to avoid race conditions.

### Frontend Architecture & State Management (Questions 26-30)

26. Explain the Redux state management implementation. How is `redux-persist` used to maintain authentication state across page refreshes?

27. How is routing structured in the application? Explain the protected route pattern using `AuthLayout` and how unauthorized access is handled.

28. How are Custom Events used for communication between components? Explain the `voice-command` and `play-index` events and how they enable decoupled component communication.

29. Explain the axios interceptor setup. How are API requests configured with credentials, and how is error handling centralized?

30. How is the responsive design implemented? Describe how the sidebar and main content area adapt to different screen sizes, and how voice commands work on mobile devices.
